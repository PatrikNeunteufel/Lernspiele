# Notizen für Zwischenergebnisse (Entscheid NZ1 a, LERN_Session13)

Kleine, nicht bewertete Felder (`LS.notizFeld()`, Klasse `zw-notiz`) genau dort, wo das Zwischenergebnis hingehört.
Ob sie erscheinen, regelt die Einstellung der Aufsicht „Notizen für Zwischenergebnisse“ (global und je Spiel):
**nach Stufe** (Standard) · **immer** · **nie (Kopfrechnen)**. Das Spiel sagt mit `ctx.notizen(empfohlen)`, ob es bei
„nach Stufe“ Notizen zeigen würde; der Rahmen hält fest, ob das Kind sie benutzt hat (Vorgehen `notiz`: im Kopf / mit
Notizen) — daraus das Abzeichen „Kopfrechner“ (Aufgaben mit Notizfeldern im Kopf und auf Anhieb gelöst; Zusatz Patrik).

Erhebung über alle 168 Spiele (Helfer, nur gelesen, LERN_Session13). „ab“ = Vorschlag für „nach Stufe“; unsicher
Markiertes vor dem Bau ansehen. Skala: s1 eine Klasse tiefer · s2–s4 Basisklasse · s5 nächste Klasse · s6 Königsstufe.

## Haben schon Felder

schriftlich-werkstatt, malkreuz (s5/s6 allenfalls ein Feld neben dem Gesamtfeld), zahlenmauer, zielzahl-jagd,
platzhalter-geschichten, quader-volumen s1, rechteck-labor (Laborbuch in s5; ob „immer“ es in s6 zeigt, offen),
geheimschrift-knacker.
